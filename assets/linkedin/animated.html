From Detection to Action

An agentic LLM framework that turns fault-detection signals into validated, constraint-aware recovery actions for process plants.

Recovery workflow — agent layer
FAULT DETECTED
Monitoring AgentRULE-BASED

Watches synchronized sensor and actuator streams, flags deviations from nominal behavior, and contextualizes the fault.

Planning AgentLLM

Retrieves the plant's state-machine context via Graph RAG and proposes a minimal-risk recovery path.

Action AgentLLM

Synthesizes concrete commands and setpoint changes that respect interlocks, limits, and rate constraints.

Simulation AgentDETERMINISTIC

Runs the candidate action set against the digital plant twin to test dynamic feasibility before actuation.

Validation AgentDETERMINISTIC

Checks the simulated outcome against safety envelopes and acceptance criteria. On revise, structured feedback loops back to Planning/Action for a bounded number of refinement attempts.
